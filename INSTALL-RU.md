# ServerHub — меню сервера (установка)

Отдельный мод. Ставится рядом с SimpleMenu, они друг другу не мешают:
у SimpleMenu команда `/menu`, у этого мода — `/hub`.

---

## Что делает

Команда **`/hub`** открывает окно «МЕНЮ СЕРВЕРА» с тремя большими кнопками:

- **ПРАВИЛА** — открывает окно с заголовком «ПРАВИЛА» и текстом правил;
- **МИНИ-ИГРЫ** — открывает окно с заголовком «МИНИ-ИГРЫ»;
- **ДИСКОРД СЕРВЕР** — открывает окно с заголовком «ДИСКОРД СЕРВЕР» и ссылкой.

В каждом окне раздела внизу есть кнопка **НАЗАД** (возвращает в главное меню)
и **ЗАКРЫТЬ**. Клавиша ESC тоже закрывает меню.

---

## Шаг 1. Скачать готовый файл

1. Открой <https://github.com/ayaft1445-eng/myht/releases/latest>
2. Внизу, в разделе **Assets**, нажми на файл **`ServerHub-1.0.0.jar`**.

## Шаг 2. Поставить на сервер

1. Останови сервер.
2. Положи файл в папку **`plugins`** сервера (рядом с `SimpleMenu-1.1.0.jar`, если он там).
3. Запусти сервер.

## Шаг 3. Проверить

В консоли сервера после запуска должна быть строка:

```
[ServerHub] Loaded. Type /hub in chat to open the server menu.
```

В игре: напиши в чат `/hub` → открылось меню с тремя кнопками → нажми любую →
открылось окно раздела с его названием → нажми «НАЗАД» → вернулся в меню.

## Что поменять под свой сервер

Папка с текстами: `src/main/resources/Common/UI/Custom/ServerHub/`

| Что | Файл | Что искать |
|---|---|---|
| **Ссылка на Discord** | `Section_Discord.ui` | `discord.gg/ЗАМЕНИ-НА-СВОЮ-ССЫЛКУ` |
| Текст правил | `Section_Rules.ui` | строки `Text: "1. Уважай других игроков...";` |
| Текст в «Мини-играх» | `Section_Minigames.ui` | строки `Text: "...";` |
| Названия кнопок | `Main.ui` | `Text: "ПРАВИЛА";` и т.д. |
| Заголовок окна раздела | `Section_*.ui` | первая строка `Text: "ПРАВИЛА";` |
| Размер главного окна | `Main.ui` | `Anchor: (Width: 640, Height: 520);` |
| Размер окна раздела | `Section_*.ui` | `Anchor: (Width: 860, Height: 600);` |
| Цвет кнопок | `Main.ui` | `Background: #7c3aed` (и `#8b5cf6` при наведении) |
| Название команды | `src/main/java/dev/hytalemodding/serverhub/commands/HubCommand.java` | `super("hub", ...)` |

Строки правил можно добавлять и убирать: скопируй целиком блок `Label { ... }`
вместе со следующим за ним `Group { Anchor: (Height: 10); }` (это отступ).

После правок нужно заново собрать jar: залей изменённые файлы в репозиторий,
вкладка **Actions** → дождись зелёной галочки → свежий файл появится
на странице Releases. Затем замени jar на сервере и перезапусти его.

## Как это устроено внутри

```
src/main/java/dev/hytalemodding/serverhub/
├── ServerHubPlugin.java        главный файл: регистрирует команду /hub
├── commands/HubCommand.java    команда /hub
└── ui/HubPage.java             логика: какое окно показывать

src/main/resources/
├── manifest.json               описание плагина для сервера
└── Common/UI/Custom/ServerHub/
    ├── Main.ui                 главное окно с тремя кнопками
    ├── Section_Rules.ui        окно «Правила»
    ├── Section_Minigames.ui    окно «Мини-игры»
    └── Section_Discord.ui      окно «Дискорд сервер»
```

Каждое окно — отдельный файл разметки. Когда игрок нажимает кнопку, сервер
открывает ему ту же страницу, но с другим номером раздела, и окно собирается
заново целиком. Поэтому заголовок, текст и кнопки всегда соответствуют разделу.
