# HubMenu — чёрно-белое меню сервера

Отдельный мод. Ставится рядом с SimpleMenu и не мешает ему:
у SimpleMenu команда `/menu`, у этого мода — `/hub`.

---

## Что делает

Команда **`/hub`** открывает окно **HUB** — чёрный фон, белая обводка,
четыре кнопки-карточки:

- **МИНИ-ИГРЫ** — открывает окно со списком режимов;
- **НОВОСТИ** — открывает окно с новостями сервера;
- **ПРАВИЛА** — открывает окно с правилами сервера;
- **ДС СЕРВЕР** — открывает окно со ссылкой на Discord.

В каждом окне раздела внизу кнопки **НАЗАД** и **ЗАКРЫТЬ**, ESC тоже закрывает.
При наведении на карточку она становится белой, а текст — чёрным.

---

## Установка

1. Скачай `HubMenu-1.2.0.jar`: <https://github.com/ayaft1445-eng/myht/releases/latest>
   (файл внизу страницы, в разделе **Assets**).
2. Останови сервер.
3. Положи файл в папку **`plugins`** сервера.
4. Запусти сервер. В консоли должна появиться строка:
   `[HubMenu] Loaded. Type /hub in chat to open the menu.`
5. В игре напиши `/hub`.

Если раньше стоял `ServerHub-1.0.0.jar` — удали его, этот мод пришёл ему на замену.

## Что поменять под свой сервер

Папка с разметкой: `src/main/resources/Common/UI/Custom/HubMenu/`

| Что | Файл | Что искать |
|---|---|---|
| **Ссылка на Discord** | `Section_Discord.ui` | `discord.gg/ЗАМЕНИ-НА-СВОЮ-ССЫЛКУ` |
| Подписи на кнопках | `Main.ui` | `Text: "МИНИ-ИГРЫ";`, `Text: "НОВОСТИ";`, `Text: "ДС СЕРВЕР";` (в блоках `Label`) |
| Ширина кнопок | `Main.ui` | `Anchor: (Width: 340, ...)` — у каждой карточки своя, сумма с отступами должна влезать в ширину окна |
| Заголовок HUB | `Main.ui` | `Text: "HUB";` |
| Размер окна | любой файл | `Anchor: (Width: 1280, Height: 620);` в начале |
| Прозрачность фона | любой файл | число в скобках: `#000000(0.60)` — меньше значит прозрачнее |
| Подпись на карточке | `Main.ui` | `Label` с `Bottom: 20` — отступ подписи от низа |
| Картинка на карточке | `Main.ui` | `Background: (TexturePath: "Assets/Card_Minigames.png")` — свои PNG клади в `Common/UI/Custom/HubMenu/Assets/` |
| Толщина белой обводки | любой файл | полоски `Group { Anchor: (Height: 2); Background: #ffffff; }` и `(Width: 2)` |
| Текст новостей | `Section_News.ui` | строки `Text: "...";` |
| Режимы мини-игр | `Section_Minigames.ui` | строки `Text: "...";` |
| Название команды | `src/main/java/dev/hytalemodding/hubmenu/commands/HubCommand.java` | `super("hub", ...)` |

Белая обводка собрана из четырёх тонких полосок по краям. Так сделано специально:
если залить белым всю подложку, полупрозрачный чёрный смешается с ней и станет серым.
Хочешь рамку толще — поменяй `2` на `3` в полосках.

После правок: залей файлы в репозиторий → вкладка **Actions** → дождись зелёной
галочки → свежий jar появится в Releases.

## Картинки на карточках

У каждой кнопки главного окна свой фон в духе Hytale: арена со щитом и мечами
(мини-игры), доска объявлений у деревни (новости), каменная скрижаль (правила),
кристалл связи (Discord). Файлы лежат тут:

```
src/main/resources/Common/UI/Custom/HubMenu/Assets/
├── Card_Minigames.png   520×470
├── Card_News.png        240×470
├── Card_Rules.png       240×470
└── Card_Discord.png     240×470
```

В разметке картинка подключается одной строкой внутри карточки:

```
Group { Anchor: (Full: 0); Background: (TexturePath: "Assets/Card_Minigames.png"); }
```

Важные мелочи:

- путь пишется относительно `.ui`-файла, поэтому просто `Assets/...`;
- в `manifest.json` должно стоять `"IncludesAssetPack": true` — иначе вместо
  картинки клиент покажет красный крест;
- ниже картинки лежит однотонная подложка — её видно, если текстура не загрузилась;
- поверх картинки лежит сама кнопка: при наведении она подсвечивает фон,
  при нажатии заливает его красным. Настраивается в стиле `@Card` в начале файла;
- низ картинок затемнён специально — чтобы подпись на карточке читалась.

**Свои картинки.** Положи PNG нужного размера в `Assets/` и поменяй имя файла
в `Main.ui`. Размер лучше держать тот же, иначе картинка растянется.

**Перерисовать штатные.** Они собраны скриптом `tools/generate_card_art.py`
(нужны Python 3 и `pip install pillow numpy`):

```
python3 tools/generate_card_art.py
```

Сцены и цвета описаны прямо в скрипте — по функции на карточку. Для обычной
сборки мода запускать его не нужно, PNG уже лежат в репозитории.

## Палитра

Тёмный стиль: почти чёрный фон с лёгким переходом, тонкие рамки, белый капс,
красный акцент.

| Что | Код |
|---|---|
| Фон окна | переход `#0b0b0c` → `#17171a` |
| Фон карточек | переход `#101012` → `#1c1c20` |
| Рамка выделенной карточки | `#f2f2f2` |
| Рамка остальных | `#3a3a3e` |
| Акцент (черта под заголовком, ESC, метки) | `#c8102e` |
| Текст | `#ffffff`, описания `#b8b8bd`, приглушённое `#6e6e74` |

Фиолетовая версия сохранена в папке `palettes/purple` — если захочешь вернуть,
скопируй файлы оттуда в `src/main/resources/Common/UI/Custom/HubMenu`.
