# HubMenu — тёмно-фиолетовое меню сервера

Отдельный мод. Ставится рядом с SimpleMenu и не мешает ему:
у SimpleMenu команда `/menu`, у этого мода — `/hub`.

---

## Что делает

Команда **`/hub`** открывает окно **HUB** в тёмно-фиолетовом стиле (раскладка —
по мотивам меню игры White Knuckle): почти чёрный фон с фиолетовым отливом,
тонкие рамки, белые заголовки капсом и яркий фиолетовый акцент. Четыре карточки:

- **МИНИ-ИГРЫ** — открывает окно со списком режимов;
- **НОВОСТИ** — открывает окно с новостями сервера;
- **ПРАВИЛА** — открывает окно с правилами сервера;
- **ДС СЕРВЕР** — открывает окно со ссылкой на Discord.

В окне раздела вверху слева кнопка **НАЗАД**, ESC закрывает меню.
При наведении карточка подсвечивается фиолетовым.

---

## Установка

1. Скачай `HubMenu-3.1.0.jar`: <https://github.com/ayaft1445-eng/myht/releases/latest>
   (файл внизу страницы, в разделе **Assets**).
2. Останови сервер.
3. В папке **`mods`** сервера удали старый `HubMenu-….jar`, если он был, и положи новый.
4. Запусти сервер. В консоли должна появиться строка:
   `[HubMenu] Loaded. Type /hub in chat to open the menu.`
5. В игре напиши `/hub`.

Если раньше стоял `ServerHub-1.0.0.jar` — удали его, этот мод пришёл ему на замену.

## Что поменять под свой сервер

Папка с разметкой: `src/main/resources/Common/UI/Custom/HubMenu/`

| Что | Файл | Что искать |
|---|---|---|
| **Ссылка на Discord** | `Section_Discord.ui` и `src/main/java/dev/hytalemodding/hubmenu/ui/HubMenuPage.java` | `discord.gg/ЗАМЕНИ-НА-СВОЮ-ССЫЛКУ` |
| Подписи на карточках | `Main.ui` | `Text: "МИНИ-ИГРЫ";`, `Text: "НОВОСТИ";`, `Text: "ПРАВИЛА";`, `Text: "ДС СЕРВЕР";` (в блоках `Label`) |
| Ширина карточек | `Main.ui` | `Anchor: (Width: 520, Height: 470);` у большой и `Width: 240` у остальных — сумма с отступами должна влезать в ширину окна |
| Заголовок HUB | `Main.ui` | `Text: "HUB";` |
| Размер окна | любой файл | `Anchor: (Width: 1440, Height: 660);` в начале |
| Прозрачность фона | любой файл | число в скобках: `#0a0612(0.88)` — меньше значит прозрачнее |
| Подпись на карточке | `Main.ui` | `Label` с `Bottom: 22` — отступ подписи от низа |
| Толщина рамок | любой файл | полоски `Group { Anchor: (Height: 2); … }` и `(Width: 2)` |
| Текст новостей | `Section_News.ui` | строки `Text: "...";` |
| Правила | `Section_Rules.ui` | строки `Text: "...";` |
| Режимы мини-игр | `Section_Minigames.ui` | строки `Text: "...";` |
| Название команды | `src/main/java/dev/hytalemodding/hubmenu/commands/HubCommand.java` | `super("hub", ...)` |

Рамка собрана из четырёх тонких полосок по краям. Так сделано специально:
если залить цветом всю подложку, полупрозрачный фон смешается с ней.
Хочешь рамку толще — поменяй `2` на `3` в полосках.

После правок: залей файлы в репозиторий → вкладка **Actions** → дождись зелёной
галочки → свежий jar появится в Releases.

## Палитра

Тёмно-фиолетовый стиль. Переходы цвета собраны из десяти полос с промежуточными
оттенками (настоящих градиентов в разметке нет). Число в скобках у цвета — прозрачность.

| Что | Код |
|---|---|
| Фон окна | переход `#0a0612` → `#1c1131`, прозрачность `0.88` |
| Фон карточек | переход `#140c22` → `#28183f`, прозрачность `0.75` |
| Рамка выделенной карточки | `#d8c4ff` |
| Рамка окна и остальных карточек | `#3a2a55` |
| Акцент (черта под заголовком, «ESC — ЗАКРЫТЬ», «ДОСТУПНО», ссылка Discord) | `#a35dff` |
| Подсветка карточки при наведении / нажатии | `#a35dff(0.16)` / `#a35dff(0.32)` |
| Кнопки «НАЗАД» и «ПОЛУЧИТЬ ССЫЛКУ» | обычная `#c9b3ff(0.06)`, при наведении `#a35dff(0.55)`, при нажатии `#a35dff(0.80)` |
| Текст | заголовки `#ffffff`, описания `#bfb2d9`, приглушённое `#6f6189` |

Чтобы сменить акцент, замени `#a35dff` во всех пяти файлах на другой цвет
(поиск и замена в редакторе).

Другие варианты сохранены в папке `palettes`:

- `palettes/dark-red` — прежний тёмный стиль с красным акцентом (версия 3.0.0);
- `palettes/purple` — светлая фиолетовая палитра (версии до 3.0.0).

Чтобы вернуть вариант, скопируй файлы из его папки в
`src/main/resources/Common/UI/Custom/HubMenu`.

```
    ├── Section_Rules.ui      окно «Правила»

```
