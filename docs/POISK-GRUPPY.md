# Поиск группы — как это работает и как настроить

Часть мода **HubMenu**. Игрок встаёт в очередь на мини-игру, мод ждёт, пока
наберётся нужное количество людей, и уносит их всех на арену этого режима.

---

## Для игрока

| Команда | Что делает |
|---|---|
| `/gf` | окно поиска группы: список режимов и кнопка «ВСТАТЬ В ОЧЕРЕДЬ» |
| `/gfstatus` | коротко в чат: что вы ищете и сколько народу в очередях |
| `/gfleave` | выйти из очереди, не открывая окно |

Второй путь — `/hub` → **МИНИ-ИГРЫ** → любая карточка. Она открывает то же
окно со списком всех режимов; в очередь никого не ставит, режим карточки
просто помечен в списке как выбранный. Кнопка **НАЗАД** возвращает обратно
в раздел «Мини-игры».

Как идёт поиск:

1. Игрок встаёт в очередь. В окне видно «в очереди 1 из 2».
2. Как только набирается минимум, начинается отсчёт — всем в очереди
   капает в чат «старт через 5 с».
3. По нулю первые игроки (сколько влезает в максимум группы) уходят на
   арену, очередь освобождается под следующую группу. Перенос занимает
   пару секунд: мод дожидается, пока игрок правда окажется на месте.
4. Если кто-то вышел и людей снова не хватает — отсчёт отменяется,
   ожидание продолжается.

Игрок может стоять только в одной очереди. Встал в другую — из прошлой
выходит сам.

## Для админа

Панель: **`/gfadmin`**.

### Кто считается админом

1. Ник есть в списке `admins` файла настроек, **или**
2. у игрока есть право `hubmenu.groupfinder.admin`.

Пока список `admins` пуст, панель открыта всем — иначе первый владелец
сервера не смог бы себя добавить. В этом состоянии панель показывает
красную полосу, а в консоль уходит предупреждение. Зайдите в `/gfadmin`,
нажмите **СДЕЛАТЬ СЕБЯ АДМИНОМ** — и панель закроется для остальных.

### Первое окно: список режимов

Сверху — общие настройки:

| Что | Зачем |
|---|---|
| **СИСТЕМА** | выключатель всего поиска группы разом |
| **ОПОВЕЩЕНИЯ В ЧАТ** | писать ли всем «идёт набор в …» |
| **ТАЙМАУТ ОЧЕРЕДИ** | через сколько выкидывать из очереди, если никого не нашлось; «выкл» — ждать вечно |

Дальше строка на каждый режим: ключ, границы по игрокам, отсчёт, точка
телепорта и сколько человек сейчас в очереди. Кнопка **ВКЛ/ВЫКЛ**
включает режим, **НАСТРОИТЬ** открывает его окно.

Внизу: **ДОБАВИТЬ РЕЖИМ**, **ПЕРЕЧИТАТЬ ФАЙЛ** (если правили
`groupfinder.json` руками) и **ДИАГНОСТИКА** (пишет в чат, какие серверные
методы мод нашёл — пригодится, если телепорт не сработал).

### Второе окно: настройка режима

| Строка | Что делает |
|---|---|
| **СОСТОЯНИЕ** | включить режим. Без точки телепорта включить нельзя |
| **МИНИМУМ ИГРОКОВ ДЛЯ СТАРТА** | сколько нужно набрать, чтобы пошёл отсчёт |
| **МАКСИМУМ ИГРОКОВ В ГРУППЕ** | сколько человек заберёт одна группа |
| **ОТСЧЁТ ПЕРЕД ТЕЛЕПОРТОМ** | 0 — уносит сразу, как набралось |
| **РАЗБРОС ВОКРУГ ТОЧКИ** | 0 — все в одну точку; больше нуля — раскидывает по кругу, чтобы не появлялись друг в друге |
| **КНОПКА В ОКНЕ «МИНИ-ИГРЫ»** | какая карточка помечает этот режим в списке. Одна карточка — один режим |
| **ТОЧКА ТЕЛЕПОРТА** | куда уносит группу |

Точку не нужно набирать цифрами: встаньте в игре там, где должна начинаться
мини-игра, и нажмите **ПОСТАВИТЬ ТОЧКУ ЗДЕСЬ**. Кнопка **ПРОВЕРИТЬ** тут же
унесёт туда вас самих — удобно убедиться, что точка не в стене.

Ещё в этом окне: **ОЧИСТИТЬ ОЧЕРЕДЬ** и **УДАЛИТЬ РЕЖИМ**.

### Быстрая настройка с нуля

1. `/gfadmin` → **СДЕЛАТЬ СЕБЯ АДМИНОМ**.
2. Встаньте на арену первой мини-игры.
3. **НАСТРОИТЬ** у нужного режима → **ПОСТАВИТЬ ТОЧКУ ЗДЕСЬ**.
4. Выставьте минимум и максимум игроков.
5. **СОСТОЯНИЕ** → «ВКЛЮЧЁН».
6. Проверьте: `/gf` — режим должен показывать «ВСТАТЬ В ОЧЕРЕДЬ».

## Файл настроек

`<папка плагина>/groupfinder.json`. Панель пишет в него сама, но файл можно
править и руками — после правок нажмите **ПЕРЕЧИТАТЬ ФАЙЛ** в панели.

```json
{
  "version": 1,
  "enabled": true,
  "announce": true,
  "queueTimeoutSeconds": 0,
  "admins": ["ВашНик"],
  "modes": [
    {
      "id": "ctf",
      "name": "ЗАХВАТ ФЛАГА",
      "enabled": true,
      "minPlayers": 2,
      "maxPlayers": 2,
      "countdownSeconds": 5,
      "spreadRadius": 0,
      "cardIndex": 0,
      "arena": {
        "set": true,
        "world": "hub",
        "x": 120.5,
        "y": 64,
        "z": -35.3,
        "yaw": 90,
        "pitch": 0
      }
    }
  ]
}
```

| Поле | Смысл |
|---|---|
| `id` | ключ режима, по нему мод ищет очередь. Латиницей, без пробелов |
| `name` | название в окне. **Меняется только здесь** — в панели кнопок для ввода текста нет |
| `cardIndex` | номер карточки в окне «Мини-игры»: 0 — первая, 3 — четвёртая, −1 — не привязан |
| `arena.world` | имя мира. Пустая строка — «тот же мир, где стоял игрок» |
| `arena.set` | `false` — точка не задана, режим работать не будет |

Если файл окажется битым, мод не уронит сервер: отложит файл в
`groupfinder.json.broken` и поднимется на настройках по умолчанию.

В панели видно шесть режимов — остальные останутся в файле и будут работать,
но настроить их получится только там.

## Если что-то не работает

**Режим не включается.** Не задана точка телепорта — поставьте её.

**Группа собирается, но никого не уносит.** Мод пробует несколько способов
переноса по очереди и после каждого смотрит, где игрок оказался на самом
деле: вызов, который «прошёл», но не сдвинул игрока, за успех не считается.
Сработавший способ запоминается и дальше идёт первым.

В консоли это видно построчно:

```
[Поиск группы] перенос: способ «player.moveTo» не сдвинул Steve, пробуем следующий
[Поиск группы] перенос удался способом «Teleport-компонент» · Steve
```

Если не помог ни один — будет строка `перенос не удался (...)` со списком
всех способов и причин. Текущий рабочий способ показывает `/gfadmin` →
**ДИАГНОСТИКА**, строка «способ переноса».

**Кнопка в меню пишет «к этой карточке ещё не привязан режим».**
В настройке режима переключите **КНОПКА В ОКНЕ «МИНИ-ИГРЫ»** на нужный номер.

**Панель открывается у всех подряд.** Список админов пуст — нажмите
**СДЕЛАТЬ СЕБЯ АДМИНОМ**.
