# DeathMatch — дезматч для Hytale

Отдельный мод. Игроки дерутся на арене, за убийства растёт уровень, и на
каждом уровне выдаётся новый комплект: оружие в руки, броня в слоты.
По умолчанию уровни включаются на **0, 10, 20 и 30 убийствах**.

Ставится рядом с [HubMenu](https://github.com/ayaft1445-eng/myht) и цепляется
к его меню, но работает и без него.

---

## Как это связано с меню HubMenu

Связь через место, а не через код: моды не знают о классах друг друга и
обновляются порознь.

1. В меню HubMenu карточка мини-игры ставит игрока в очередь поиска группы.
2. Когда группа набралась, поиск телепортирует всех на точку своего режима.
3. Дезматч раз в две секунды смотрит, кто стоит внутри круга **своей** арены,
   и начинает бой для них.

Значит, чтобы карточка мини-игры в меню вела в дезматч, обе точки должны
стоять в одном месте:

- в дезматче — встаньте на арену и наберите **`/dmsetarena`**;
- в HubMenu — откройте `/gfadmin`, зайдите в режим и нажмите
  **«ПОСТАВИТЬ ТОЧКУ ЗДЕСЬ»**, стоя там же.

Без HubMenu дезматч тоже работает: игроки приходят на арену ногами, бой
начинается сам.

## Установка

1. Скачайте `DeathMatch-1.0.0.jar` в разделе
   [Releases](https://github.com/ayaft1445-eng/hytale-deathmatch/releases/latest).
2. Остановите сервер.
3. Положите файл в папку **`plugins`**.
4. Запустите сервер. В консоли появится строка
   `[Дезматч] Загружен. /dm — состояние, /dmadmin — настройки.`
5. Зайдите в игру и наберите **`/dmadmin`** — первый, кто это сделает, станет
   админом дезматча.
6. Встаньте на арену и наберите **`/dmsetarena`**.

## Команды

| Команда | Кому | Что делает |
|---|---|---|
| `/dm` | всем | сколько убийств, какой уровень, сколько до следующего |
| `/dmtop` | всем | таблица текущего матча |
| `/dmleave` | всем | выйти из боя, не уходя с арены ногами |
| `/dmadmin` | админу | состояние настроек, список уровней и остальных команд |
| `/dmsetarena` | админу | поставить точку арены там, где вы стоите |
| `/dmgive` | админу | выдать себе комплекты всех уровней и увидеть, какие предметы сервер не знает |
| `/dmreload` | админу | перечитать `deathmatch.json` без перезапуска |
| `/dmreset` | админу | обнулить счёт матча |
| `/dmtoggle` | админу | включить или выключить дезматч |
| `/dmdiag` | админу | что мод нашёл в серверном API на этой сборке |

Аргументов у команд нет намеренно: на каждое действие своя команда, помнить
синтаксис не нужно.

## Настройки

Файл: `<папка плагина>/deathmatch.json`. Создаётся при первом запуске.

```json
{
  "enabled": true,
  "arena": { "set": true, "world": "", "x": 120.5, "y": 64.0, "z": -35.2 },
  "radius": 60,
  "goalKills": 30,
  "announce": true,
  "resetLevelOnDeath": false,
  "regiveOnRespawn": true,
  "admins": ["ваш_ник"],
  "levels": [
    {
      "kills": 0,
      "name": "НОВИЧОК",
      "weapon": "hytale:wooden_sword",
      "helmet": "",
      "chest": "hytale:leather_chestplate",
      "hands": "",
      "legs": "",
      "extras": []
    }
  ]
}
```

| Поле | Что значит |
|---|---|
| `arena` | центр арены; пустой `world` — тот же мир, в котором стоял игрок |
| `radius` | радиус круга боя в блоках; по высоте допуск вдвое больше |
| `goalKills` | сколько убийств заканчивают матч; `0` — матч не кончается |
| `announce` | писать ли о входах, уровнях и победах в общий чат |
| `resetLevelOnDeath` | `true` — смерть сбрасывает уровень до первого |
| `regiveOnRespawn` | выдавать ли комплект заново, когда боец вернулся на арену |
| `levels` | уровни по возрастанию `kills`; первый — стартовый комплект |
| `extras` | что ещё положить в хотбар: зелья, блоки, стрелы |

Счёт бойца **переживает смерть**: игрок возрождается на спавне, возвращается
на арену и продолжает с теми же убийствами. Выйти из матча совсем — `/dmleave`
или уйти с арены и не возвращаться.

## Идентификаторы предметов

`weapon`, `helmet`, `chest`, `hands`, `legs` и `extras` — это строки ассетов
сервера, например `hytale:iron_sword`. **Набор предметов на разных сборках
разный**, и мод заранее его не знает: неизвестный идентификатор просто не
выдастся, а в консоль уйдёт строка.

Поэтому идентификаторы из коробки — это заготовка, а не готовый список.
Проверять их так:

1. `/dmgive` — мод выдаст комплекты всех уровней по очереди и напишет, что не
   выдалось;
2. поправьте `deathmatch.json`;
3. `/dmreload`.

---

## Чего мод пока не делает

- **Не возвращает на арену после смерти.** Игрок возрождается на своём спавне
  и приходит обратно сам; счёт при этом сохраняется. Телепорт после смерти —
  следующий шаг.
- **Не считает убийства мобами и падения.** Засчитывается только удар от
  другой сущности; падения, утопления и самоубийства не идут в счёт.
- **Не делит на команды.** Все против всех.

## Сборка

```
./gradlew build
```

Нужен JDK 25. Готовый jar — в `build/libs/`. Сборка и публикация релиза
настроены в `.github/workflows/gradle.yml`: пуш в любую ветку собирает jar и
кладёт его в Releases.

## Из чего состоит

```
src/main/java/dev/hytalemodding/deathmatch/
├── DeathMatchPlugin.java      команды, события, запуск арены
├── match/MatchService.java    кто в бою, счёт, уровни, объявления
├── match/Equipment.java       выдача оружия и брони
├── match/Fighter.java         один боец: убийства, смерти, уровень
├── systems/KillSystem.java    ECS-система: ловит убийства
├── model/                     настройки, уровни, точка арены
├── storage/                   deathmatch.json и разбор JSON
├── commands/                  /dm, /dmadmin и остальные
└── bridge/ServerApi.java      вызовы серверного API через рефлексию
```

`ServerApi` — тот же мост, что и в HubMenu: координаты, миры, права и папка
данных на разных сборках сервера называются по-разному, поэтому такие вызовы
собраны в одном месте и ищутся через рефлексию. Если что-то не нашлось,
`/dmdiag` покажет, что именно.
