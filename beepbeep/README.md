# BeepBeep VehicleCore 0.4.0

Серверный плагин Hytale (сервер 0.6.8): физичная подвеска, коллизии кузова и посадка
в машину на несколько мест. Работает вместе с паком моделей `BeepBeep_Vehicle_Pack`.

## Что нового в 0.4.0 — посадка

- В машине столько мест, сколько описано в профиле (`seats`, до 16). Одно место —
  водительское, остальные пассажирские.
- Седок сидит на своём месте как приклеенный: вместе с машиной поворачивает,
  наклоняется на подъёмах и кренится на неровностях. Другие игроки видят его в позе
  «сидит», а сам он в виде сзади видит себя на сиденье.
- Управление перехватывается по-новому (см. «Как это работает»), без NPC-маунта и без
  рефлексии, поэтому клиент больше не «перетягивает» машину на себя.

## Управление

| Действие | Клавиша |
|---|---|
| Сесть в машину | **F** (Использовать), глядя на машину |
| Газ / задний ход | **W** / **S** |
| Руль | **A** / **D** |
| Ручник | **Пробел** |
| Выйти | зажать **«присесть»** примерно на 0,7 с (или `/vehicle dismount`) |
| Сменить вид (сзади → от первого лица → вокруг машины) | **средняя кнопка мыши** |

Садится игрок на ближайшее к нему свободное место: подошли к водительской двери — сели
за руль, к задней — сели назад.

## Команды

Все команды — подкоманды `/vehicle`. Команды посадки (`mount`, `seat`, `dismount`,
`view`, `seats`) требуют права `beepbeep.vehicle.ride`, которое по умолчанию выдаётся
всем игрокам (группа `hytale:Adventurer`); остальные — права `beepbeep.vehicle.admin`.

| Команда | Что делает |
|---|---|
| `/vehicle spawn` | создать машину по профилю рядом с собой |
| `/vehicle mount` | сесть на ближайшее свободное место ближайшей машины |
| `/vehicle seat <номер>` | сесть на место с этим номером или пересесть на него |
| `/vehicle dismount` | выйти |
| `/vehicle view first\|third\|chase` | вид камеры |
| `/vehicle seats` | список мест машины и кто где сидит |
| `/vehicle status` | диагностика ввода, камеры и шасси |
| `/vehicle seatcfg` | перечитать `seating.json` |
| `/vehicle debug start` / `stop` | записать 90 секунд подробной диагностики в файл |
| `/vehicle edit` | редактор профиля (в том числе места) |
| `/vehicle drive` / `stop` | старое управление «снаружи», когда идёшь рядом с машиной |
| `/vehicle clear` | удалить все машины |

## Места в профиле

Места задаются в профиле машины (`profiles/*.json` в папке данных мода или через
`/vehicle edit`):

```json
"seats": [
  { "id": "driver",          "position": { "x": -0.45, "y": 1.05, "z":  0.55 }, "yaw": 0,   "driver": true  },
  { "id": "passenger_front", "position": { "x":  0.45, "y": 1.05, "z":  0.55 }, "yaw": 0,   "driver": false },
  { "id": "rear_left",       "position": { "x": -0.45, "y": 1.05, "z": -0.65 }, "yaw": 0,   "driver": false },
  { "id": "rear_right",      "position": { "x":  0.45, "y": 1.05, "z": -0.65 }, "yaw": 0,   "driver": false }
]
```

- Координаты — в системе машины: `x` вправо, `y` вверх, `z` вперёд, в блоках от центра
  шасси. `position` — точка, где сидит игрок.
- `yaw` — поворот кресла в градусах (180 — сидит спиной вперёд).
- Ровно одно место с `"driver": true`, всего от 1 до 16 мест.
- Если после правки профиля мест стало меньше, седоки с исчезнувших мест выходят.
- Выходят с той стороны, где место: `x < 0` — слева, иначе справа. Если там стена,
  плагин пробует другую сторону, сзади, спереди и в крайнем случае крышу.

## Настройки посадки: `seating.json`

Файл создаётся в папке данных мода при первом запуске. После правки — `/vehicle
seatcfg`, новые значения действуют со следующей посадки.

`controls` — управление:
- `mode` — `fixed`: W всегда вперёд машины (по умолчанию); `look`: W туда, куда
  смотрит игрок.
- `invertForward`, `invertSteer` — если газ или руль в игре оказались наоборот.
- `deadzone` — насколько чётко нужно нажать клавишу (0.38 — диагональ считается).
- `exitHoldSeconds` — сколько держать «присесть» для выхода.
- `enterGraceSeconds` — сколько секунд после посадки «присесть» не выбрасывает из машины.
- `middleClickCyclesView` — переключать вид средней кнопкой мыши.
- `useWish` — дополнительно брать направление из поля `wishMovement` клиента.
- `idleBrake` — тормоз без газа: `1` — машина встаёт (как раньше), `0` — катится.
- `releaseRatio` — насколько рано замечать отпускание клавиши по торможению невидимого
  персонажа (0.8; `0` — ждать его полной остановки).

`puppet` — невидимый персонаж водителя (см. ниже):
- `altitude` — высота, на которой он висит (мир Hytale — до Y 320, поэтому выше
  рельефа, но внутри мира).
- `relativeHeight` — если больше нуля, держать его на столько блоков выше машины.
- `flySpeed`, `verticalFlySpeed` — скорость его полёта.
- `recenterDistance`, `recenterHeight` — насколько он может отлететь, прежде чем его
  вернут к машине.

`camera` — камера: `defaultView` (`chase`, `third`, `first`), `eyeHeight`,
`firstPersonTilt` (вид из кабины наклоняется с машиной), `orbitDistance`, `orbitHeight`,
`orbitPitchDegrees`, `orbitMouse`, `chaseDistance`, `chaseHeight`, `chasePitchDegrees`,
`chaseRotationLerp`, `hideHeldItem`, `lockView`, `disableTargeting` (пока сидишь, мышь
не наводится на блоки, чтобы случайно их не ломать), `yawOffsetDegrees` (если камера
смотрит не вперёд машины, а назад — поставьте 180; если смотрит в небо — поменяйте знак
у `chasePitchDegrees`).

`riders` — седоки: `attachForOthers` (показывать седока пристёгнутым к месту),
`selfModel` (показывать седоку его самого на сиденье), `pose` (`sitting` или
`mounting`), `offsetY` (подвинуть седока выше/ниже точки места), `enterDistance`,
`anchorModel`, `anchorModelScale`.

## Как это работает

В 0.3.21 и 0.3.24 игрок садился на невидимого NPC через ванильный маунт. В таком режиме
клиент сам двигает маунт и шлёт серверу его позицию, поэтому машина и игрок
расходились, а клавиши приходилось угадывать по движению маунта.

Теперь:

1. Для занятого места создаётся невидимая точка крепления. Каждый тик после расчёта
   подвески она ставится на сиденье с поворотом, наклоном и креном машины.
2. Сервер держит игрока ровно на этом месте. Остальным игрокам отправляется, что игрок
   пристёгнут к точке крепления, и поза «сидит». Самому игроку этот пакет не
   отправляется, поэтому его клиент ничем не управляет.
3. Собственный персонаж игрока на его клиенте висит в воздухе высоко над машиной в
   режиме полёта, а камера клиента привязана к машине — персонажа игрок не видит.
4. Клавиши W/A/S/D двигают этого персонажа по мировым осям. Плагин через официальный
   фильтр пакетов (`PacketAdapters`) читает, куда он сдвинулся, и превращает это в газ
   и руль. Пробел поднимает персонажа — это ручник, «присесть» опускает — если держать,
   это выход. Пакеты движения седока сервер дальше не обрабатывает, кроме подтверждений
   телепорта. Когда персонаж отлетает далеко, его тихо возвращают к машине.
5. Чтобы седок в виде сзади видел себя, на его месте сидит «двойник» — копия его
   модели и облика. Двойника видит только он сам (и не в виде из кабины), остальным
   виден настоящий персонаж.
6. Камера: `chase` — сзади и сама поворачивается за машиной; `first` — с места водителя
   вперёд; `third` — сзади, мышь крутит камеру вокруг машины.

## Что проверить в игре и что прислать

Проверено сборкой против сервера 0.6.8 и юнит-тестами разбора клавиш, но в самой игре —
нет: клиент Hytale закрыт, поэтому часть поведения клиента можно проверить только у вас.

1. `/vehicle spawn`, подойти, нажать F. Если F не сажает — `/vehicle mount`.
2. Поездить: W, S, A, D, пробел. Если газ или руль перепутаны — `invertForward` или
   `invertSteer` в `seating.json`, затем `/vehicle seatcfg` и пересесть.
3. Переключить вид средней кнопкой или `/vehicle view first|third|chase`.
4. Выйти, зажав «присесть».
5. Со вторым игроком: сесть вдвоём и посмотреть друг на друга со стороны.

Если что-то не так — пришлите:
- вывод `/vehicle status`, набранной сидя в машине и нажимая клавиши;
- файл из `/vehicle debug start` → поездить 20–30 секунд → `/vehicle debug stop`
  (путь к файлу команда пишет в чат);
- что именно видно на экране.

## Известные ограничения

- Двойник, которого седок видит на своём месте, без брони и предмета в руках.
- Клавиши читаются по движению невидимого персонажа, поэтому нажатие и отпускание
  замечаются с задержкой в один-два пакета движения (обычно меньше 0,1 с).
- Пока сидишь, взаимодействие мышью с блоками и существами отключено
  (`camera.disableTargeting`), поэтому F изнутри машины не работает — выход по
  «присесть». Если выставить `disableTargeting` = `false`, F по машине может сработать
  и изнутри, но тогда кликами можно задеть блоки рядом.
- Если газ и руль начинают зависеть от того, куда повёрнута мышь, поставьте
  `controls.mode` = `look`.

## Сборка

GitHub Actions (`.github/workflows/beepbeep.yml`) собирает jar против настоящего сервера
Hytale 0.6.8 и прогоняет тесты при каждом изменении папки `beepbeep/`. Коммит с
`[release]` в сообщении публикует jar в релиз `beepbeep-latest`.

Локально: `./gradlew build` в папке `beepbeep/` (нужен доступ к maven.hytale.com).
